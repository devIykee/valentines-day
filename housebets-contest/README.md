# Housebets Contest Labs: research and prompts

Working files for two Housebets contests: the sportsbook design contest ($15,000, closes 14 Nov 2026 18:00 UTC) and the 30-second ad ($3,000).

| File | What it is |
|---|---|
| [01-FIELD-REPORT.md](01-FIELD-REPORT.md) | The official sportsbook brief, what the wireframes show, what 37 public competitor entries shipped, and where the gaps are. Start here. |
| [02-SPORTSBOOK-PROMPT.md](02-SPORTSBOOK-PROMPT.md) | Build prompt for the sportsbook prototype, with a table of what changed from v1 and why. |
| [03-AD-PROMPT-HYPERFRAMES.md](03-AD-PROMPT-HYPERFRAMES.md) | Concept, shot list and build prompt for the 30-second ad in HyperFrames. |
| [sportsbook/](sportsbook/) | **The built prototype.** Static site, no build step. See its README for the walkthrough and state links. |
| [ad/](ad/) | **The built ad.** HyperFrames project plus the rendered MP4 in `ad/renders/`. See its README for what to fix before submitting. |
| [inputs/](inputs/) | The original references doc and v1 prompt these build on. |

## Caveats

- The contest site blocks automated access. The sportsbook brief here is from a competitor's public capture dated 9 Nov 2026. Re-read the live page before submitting.
- The ad contest's brief was not available anywhere public. The ad prompt has a constraints block to fill in from the live page.
- The competitor analysis covers 37 public repos out of at least 131 entries.
- Other entries were studied to find gaps. Nothing here copies one, and the contest rules forbid it.

## Order of work

1. Fill in the ad brief and confirm the starter pack contents (see the last section of each prompt).
2. Run the sportsbook prompt. Ship stage 1 to a public URL and submit it. The rules allow three submissions a day and count your best.
3. Stages 2 and 3, each submitted separately.
4. Run the ad prompt once the product screens and Hubie art are in hand.
